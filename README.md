# Automation Exercise: Test Documentation

Manual testing documentation for the practice e-commerce website [automationexercise.com](https://automationexercise.com), created as a QA fresher portfolio project.

## What is covered
- **59 test cases** across 8 modules: Signup, Login, Logout, Products, Cart, Checkout, Contact Us, Subscription
- Test design techniques: equivalence partitioning, boundary value analysis, positive and negative testing, error guessing
- Requirement Traceability Matrix linking 9 requirements to test cases
- Bug log with severity and priority
- Test plan and test summary report
